# Formulário de cadastro — atividade HTML

Exercício de HTML com um formulário que reúne nome, sobrenome, e-mail, senha, tecnologia de interesse, nível de experiência, descrição e seleção de currículo.

## Como visualizar

Baixe e extraia o ZIP do repositório ou clone a branch do exercício:

```sh
git clone --branch exercicio_html https://github.com/GabreHell/HTML-Atividade.git
cd HTML-Atividade
```

Abra [index.html](index.html) no navegador. O projeto utiliza apenas HTML e não exige instalação de dependências ou compilação.

## Como usar

Preencha os campos, selecione as opções e experimente o botão **Limpar** para restaurar o formulário.

## Limitações

O formulário é demonstrativo: não possui integração com servidor, cadastro de usuários, autenticação ou armazenamento de dados. Selecionar um currículo não implementa seu envio a um serviço. Use dados fictícios ao experimentar.
